## 1. Actors & NIST RBAC Model

The platform implements **NIST SP 800-162 Role-Based Access Control** with 4 strictly segregated actors:

| Actor | Role | Scope |
|-------|------|-------|
| **SaaS Super Admin** | `«Cloud Provider»` | Global AWS infra, ECS, RDS, DynamoDB, SSM, Bedrock |
| **Tenant Administrator** | `«Org Admin»` | User onboarding, dept folders, quotas, DLP, AI limits |
| **Tenant Member** | `«Bob / Carol»` | Personal files, dept collab, share links, AI assistant |
| **External Guest** | `«Auditor / Partner»` | Share links, drop boxes — zero-trust only |

## 4. Tenant Lifecycle State Machine

![Tenant Lifecycle Statechart](https://github.com/FilestoreCloud/aws_nextcloud/raw/main/reports/2026-09-28/imgs/diagrams/tenant_lifecycle_statechart.png)

### States

```
[*] → PROVISIONING → ACTIVE → SUSPENDED → ACTIVE
                                    ↓
                              DEPROVISIONED → [*]
```

| State | Trigger | Compute Cost |
|-------|---------|-------------|
| `PROVISIONING` | SSM `PROVISION` action | Startup |
| `ACTIVE` | Provisioning complete | Full Fargate cost |
| `SUSPENDED` | SSM `SUSPEND` action | **\$0.00/hr** (ECS=0) |
| `DEPROVISIONED` | SSM `DEPROVISION` action | \$0.00/hr (data retained) |
