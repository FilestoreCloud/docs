# Storix Cloud Platform

**Storix** is an enterprise-grade, multi-tenant cloud storage and generative AI platform built on AWS using a Zero-Code-Modification, fully AWS-native modular CloudFormation architecture with container-per-tenant isolation.

## Architecture at a Glance

```
Internet → AWS WAFv2 → ALB (Dual-AZ Ingress)
           ├── acme.png261.dev  → tg-acme  → service-acme  [AWS Fargate ARM64]
           │                                    ├── nc_acme  [RDS Proxy -> PostgreSQL 16]
           │                                    ├── /tenants/acme/config [EFS 30d IA · 90d Archive]
           │                                    └── s3://vault/tenants/acme/* [Intelligent-Tiering]
           └── marvel.png261.dev → tg-marvel → service-marvel [AWS Fargate ARM64]
                                                ├── nc_marvel [RDS Proxy -> PostgreSQL 16]
                                                ├── /tenants/marvel/config [EFS 30d IA · 90d Archive]
                                                └── s3://vault/tenants/marvel/* [Intelligent-Tiering]

Control Plane: Step Functions SAGAs → DynamoDB Registry → Async OCC Engine → CloudWatch EMF
Telemetry:     CloudWatch Synthetics Canary (24/7 Endpoint Health) + Container Insights
AI Engine:     Nextcloud Assistant → LiteLLM (127.0.0.1:4000) → Amazon Bedrock (Claude 3.5 Sonnet)
```
