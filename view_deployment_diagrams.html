1. CI/CD Pipeline & Xác Thực OIDC Không Secret Tĩnh

Platform Engineer đẩy commit ➔ GitHub Actions bắt tay OIDC với AWS STS nhận temporary credentials của IAM Deployer Roles (Module 00-cicd).
2. Đóng Gói Container Bất Biến & Staging CloudFormation
Xem Vector SVG Ảnh PNG
Docker Buildx biên dịch Nextcloud Graviton ARM64 đẩy lên Amazon ECR; nén gói mã nguồn Lambda lên S3 Staging; kích hoạt CloudFormation.
3. Hạ Tầng Mạng, Mã Hóa & Lưu Trữ Đa Tầng
Xem Vector SVG Ảnh PNG
CloudFormation dựng VPC Multi-AZ, KMS CMK, Secrets Manager; Amazon EFS (Archive lifecycle 90d), S3 Vault, RDS PostgreSQL 16 & RDS Proxy.
4. Compute Runtime & Tự Động Bootstrap Tenant
Xem Vector SVG Ảnh PNG
ALB định tuyến HTTPS; ECS Fargate kéo Golden Image từ ECR; ECS Run-Task chạy occ maintenance:install thiết lập catalog db; EventBridge quản lý cron.
5. SuperAdmin Control Plane & SAGA Distributed Transactions
Xem Vector SVG Ảnh PNG
Cognito xác thực JWT; API Gateway proxy tới Lambda; Lambda kiểm tra version atomic trên DynamoDB (OCC) và Step Functions chạy state machine SAGA (rollback tự động).
6. Edge CDN Delivery, Dynamic DNS & Cổng Kiểm Thử 24/7
Xem Vector SVG Ảnh PNG
S3 Admin Web & CloudFront CDN phân phối React SPA; Cloudflare DNS đồng bộ subdomain; Terratest, Playwright và CloudWatch Synthetics kiểm thử 24/7.
7. Process Destroy — Quy Trình Dọn Dẹp Hạ Tầng An Toàn (Teardown Workflow)

🛡️ Quy trình Teardown theo thứ tự ngược lại của CloudFormation Stacks: Khóa xác nhận 'DESTROY' ➔ Dọn dẹp Cloudflare DNS ➔ Xóa Observability & Control Plane ➔ Dừng Compute ECS & ALB ➔ Xóa Database & Làm rỗng S3/EFS ➔ Thu hồi KMS & Xóa VPC (Đưa chi phí về 0 tuyệt đối).
