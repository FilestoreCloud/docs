# Super Admin Console

The Storix Super Admin Console is an enterprise-grade control plane application built with **React 18**, **Refine v4**, **Ant Design 5**, **TypeScript 5**, and **Vite**.

It allows platform operators to provision, inspect, clone, and manage multi-tenant Nextcloud instances with real-time operational diagnostics and FinOps cost visibility.

## 🔐 Authentication & Biometric Passkeys

The Super Admin Console provides multi-factor authentication with modern biometric credentials:

<Tabs>
  <Tab title="WebAuthn Passkeys (Touch ID / Face ID)">
    Operators can register and sign in seamlessly using **FIDO2 / WebAuthn Biometric Passkeys** (Apple Touch ID, Windows Hello, Face ID, or YubiKey hardware tokens).
    
    The backend generates cryptographically signed challenge nonces via `WEBAUTHN_CHALLENGE` and validates signatures via `WEBAUTHN_LOGIN`.
  </Tab>
  <Tab title="RFC 6238 TOTP Authenticator">
    Two-step MFA authentication using standard authenticator apps (Google Authenticator, 1Password, Authy) with SHA256 challenge tokens.
  </Tab>
  <Tab title="Secure HttpOnly Sessions">
    Session tokens are delivered via `Set-Cookie: saas_admin_session=...; HttpOnly; Secure; SameSite=Strict`, shielding authentication claims from client-side script tampering or XSS leakage.
  </Tab>
</Tabs>

## ⚡ High-Performance Smart Polling

The console incorporates intelligent polling mechanisms to reduce unnecessary network traffic and CloudWatch API charges:

```typescript
// Custom hook utilizing browser Page Visibility API and inactivity backoff
const { isVisible, isIdle } = useSmartInterval(fetchTenantMetrics, {
  activeInterval: 5000,      // Polling every 5s during active tab use
  idleInterval: 30000,       // Polling throttled to 30s after 2 mins inactivity
  pauseWhenHidden: true,     // Completely pauses fetch requests when tab is hidden
});
```

- **Page Visibility API:** Automatically ceases all log streaming and telemetry requests when the operator switches to another browser tab (`document.hidden === true`).
- **Exponential Inactivity Backoff:** Throttles interval frequency when no mouse or keyboard interaction is detected for more than 2 minutes.

## 💻 In-Browser Async OCC Command Terminal

The console features a real-time web terminal to execute Nextcloud `occ` commands without hitting HTTP timeouts:

<p align="center">
  <img src="/images/04_console_command_palette.png" alt="Command Palette and Terminal" />
</p>

### Supported Commands

- `status`: Retrieve Nextcloud version, database health, and maintenance state.
- `files:scan --all`: Recursively scan and resynchronize file cache across S3 and EFS.
- `db:add-missing-indices`: Apply missing database indices to PostgreSQL catalogs.
- `maintenance:mode --on / --off`: Toggle tenant maintenance mode.
- `app:list`: Inspect installed and enabled apps.

<Note>
  Heavy commands execute asynchronously via `EXECUTE_OCC_ASYNC`, returning an immediate `job_id` and streaming execution stdout/stderr back to the UI via `CHECK_OCC_JOB`.
</Note>

## 🛠️ Local Development & Build

### Development Server

```bash
cd console
npm install
npm run dev
# Starts local Vite development server at http://localhost:5173
```

### Production Build

```bash
npm run build
# Compiles optimized production bundle in dist/ with strict bundle budget (< 500 KB chunk)
```

### Automated Testing

```bash
npm test
# Runs 64/64 Vitest tests verifying providers, RBAC, Passkeys, and smart polling hooks
```
