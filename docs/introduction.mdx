# Storix Cloud Platform

**Storix** is an enterprise-grade multi-tenant cloud storage and generative AI platform built on Amazon Web Services (AWS) and hardened Nextcloud 30.

By leveraging a **Zero-Code-Modification, fully AWS-native modular CloudFormation architecture**, Storix combines complete data and compute isolation for each customer organization with centralized administrative governance and FinOps efficiency.

## 🏗️ Architecture at a Glance

```
Internet → AWS WAFv2 → ALB (Dual-AZ Ingress)
           ├── acme.png261.dev  → tg-acme  → service-acme  [AWS Fargate ARM64]
           │                                    ├── nc_acme  [Amazon RDS Proxy -> PostgreSQL 16]
           │                                    ├── /tenants/acme/config [Amazon EFS 30d IA · 90d Archive]
           │                                    └── s3://vault/tenants/acme/* [S3 Intelligent-Tiering]
           └── marvel.png261.dev → tg-marvel → service-marvel [AWS Fargate ARM64]
                                                ├── nc_marvel [Amazon RDS Proxy -> PostgreSQL 16]
                                                ├── /tenants/marvel/config [Amazon EFS 30d IA · 90d Archive]
                                                └── s3://vault/tenants/marvel/* [S3 Intelligent-Tiering]

Control Plane: Step Functions SAGAs → DynamoDB Registry → Async OCC Engine → CloudWatch EMF
Telemetry:     CloudWatch Synthetics Canary (24/7 SLA Probing) + Container Insights
AI Engine:     Nextcloud Assistant → LiteLLM (127.0.0.1:4000) → Amazon Bedrock (Claude 3.5 Sonnet)
```
