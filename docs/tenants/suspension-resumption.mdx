# Tenant Suspension & Resumption

One of Storix's core architectural advantages is its **FinOps Scale-to-Zero** capability. When a tenant is suspended—either by operator intervention, customer billing hold, or automated budget cap—its compute tier immediately scales to zero running tasks while preserving 100% of its data and configuration state.

---

## 💰 FinOps Resource Cost Breakdown

| Resource Tier | Active State | Suspended State | Economic Impact |
|---|---|---|---|
| **ECS Fargate Tasks** | `1-4` Tasks Running | `desiredCount: 0` (0 Tasks) | **\$0.00 / hour Compute Cost** |
| **ALB Routing Rules** | Active Host-Header Rule | Rule detached (503 / custom hold) | Prevents ingress load on sleeping cluster |
| **Amazon RDS PostgreSQL** | Active Pooled Connections | Zero Open Connections in Proxy | Connection capacity freed for other tenants |
| **Amazon EFS Config** | Live Mount | Inactive (Eligible for 30d IA transition) | Storage cost reduced by up to 92% |
| **Amazon S3 Vault** | Live Read/Write | Cold (Eligible for Glacier transition) | Storage cost reduced by up to 80% |

---

## 🖥️ Operation via SuperAdmin Console

1. Navigate to the **Tenants** list or tenant detail page in the SuperAdmin Console.
2. Select the tenant (e.g. `marvel`).
3. Click the **Suspend Tenant** or **Resume Tenant** action button.
4. The console dispatches an authenticated API request and provides real-time progress indicators.

---

## ⚡ Programmatic Execution via Control Plane API

```bash
# Suspend a tenant via Control Plane API
curl -X POST https://admin.png261.dev/api \
  -H "Authorization: Bearer <ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "SUSPEND",
    "tenant_id": "marvel"
  }'

# Verify task count scaled to zero
aws ecs describe-services \
  --cluster dev-nextcloud-cluster \
  --services service-marvel \
  --query 'services[0].desiredCount' \
  --profile storix
# Output: 0

# Resume the tenant
curl -X POST https://admin.png261.dev/api \
  -H "Authorization: Bearer <ADMIN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "action": "RESUME",
    "tenant_id": "marvel"
  }'

# Verify health status recovers cleanly
curl -s -I https://marvel.png261.dev/status.php
# Output: HTTP/2 200
```
