# Deployment Verification

After triggering deployment or making infrastructure modifications, execute the following verification checklist to assert platform integrity.

---

## 1. CloudFormation Stack Status

All 7 core stacks must report `CREATE_COMPLETE` or `UPDATE_COMPLETE`:

```bash
aws cloudformation list-stacks \
  --stack-status-filter CREATE_COMPLETE UPDATE_COMPLETE \
  --region ap-southeast-1 \
  --profile storix \
  --query "StackSummaries[*].{StackName:StackName,Status:StackStatus}" \
  --output table
```

| Stack Name | Expected Status | Component Covered |
|---|---|---|
| `<env>-nextcloud-01-networking` | `CREATE_COMPLETE` | VPC, Subnets, Route Tables, S3 Gateway Endpoint |
| `<env>-nextcloud-02-security` | `CREATE_COMPLETE` | Security Groups, KMS Keys, IAM Execution Roles |
| `<env>-nextcloud-03-storage` | `CREATE_COMPLETE` | EFS (30d IA · 90d Archive Lifecycle), S3 Vault Bucket |
| `<env>-nextcloud-04-database` | `CREATE_COMPLETE` | RDS PostgreSQL 16 & RDS Proxy Connection Pooler |
| `<env>-nextcloud-05-compute` | `CREATE_COMPLETE` | ECS Fargate Cluster (Graviton ARM64), ALB, Dedicated Cron |
| `<env>-nextcloud-06-superadmin` | `CREATE_COMPLETE` | Step Functions SAGAs, Lambda API, DynamoDB Tables |
| `<env>-nextcloud-07-observability` | `CREATE_COMPLETE` | CloudWatch Synthetics Canary (24/7 SLA), Telemetry Dashboard |

## 2. Platform Health & Ingress Endpoints

```bash
# Retrieve ALB DNS Ingress URL
ALB_URL=$(aws cloudformation describe-stacks \
  --stack-name dev-nextcloud-05-compute \
  --profile storix \
  --region ap-southeast-1 \
  --query "Stacks[0].Outputs[?OutputKey=='LoadBalancerURL'].OutputValue" \
  --output text)

# Global status check
curl -s -I "${ALB_URL}/status.php"
# Expected: HTTP/2 200 OK

# Tenant Host-Header status checks
curl -s -I https://acme.png261.dev/status.php
curl -s -I https://marvel.png261.dev/status.php
# Expected: HTTP/2 200 OK
```
