# Deployment Verification

## Retrieve Stack Outputs

```bash
aws cloudformation describe-stacks \
  --stack-name nextcloud-test \
  --region "${AWS_REGION}" \
  --query 'Stacks[0].Outputs[*].[OutputKey,OutputValue]' \
  --output table
```

## Nextcloud Health Check

```bash
ALB_URL=$(aws cloudformation describe-stacks \
  --stack-name nextcloud-test \
  --region "${AWS_REGION}" \
  --query "Stacks[0].Outputs[?OutputKey=='LoadBalancerURL'].OutputValue" \
  --output text)

curl -I "${ALB_URL}/status.php"
# Expected: HTTP/2 200
```

## Per-Tenant Health Check

```bash
curl -I "https://acme.your-domain.com/status.php"
curl -I "https://marvel.your-domain.com/status.php"
```

## Run Integration Tests

```bash
# Always target tests/ — do NOT run bare pytest
pytest tests/ -v
```
