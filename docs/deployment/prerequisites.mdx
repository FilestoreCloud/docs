# Deployment Prerequisites

Before deploying the Storix platform, ensure your local environment and AWS account satisfy the following prerequisites.

---

## 🛠️ Required Tools

| Tool | Minimum Version | Installation / Reference |
|---|---|---|
| **AWS CLI** | `v2.15+` | [AWS CLI Installation Guide](https://docs.aws.amazon.com/cli/latest/userguide/install-cliv2.html) |
| **Python** | `3.11+` (3.12 recommended) | `brew install python` |
| **Node.js** | `18+` (20 recommended) | `brew install node` |
| **Docker** | `24+` with Buildx | [Docker Desktop](https://docker.com) |
| **GitHub CLI (`gh`)**| `2.40+` | `brew install gh` |
| **awsdac** | Latest | [AWS Diagram as Code](https://github.com/awslabs/diagram-as-code) |

---

## 🔐 AWS Credentials & Profile

```bash
# Verify AWS CLI authentication with the 'storix' profile
aws sts get-caller-identity --profile storix --region ap-southeast-1
```

<Note>
  The deployment IAM role requires permissions to manage CloudFormation, VPC, ECS Fargate, RDS PostgreSQL, RDS Proxy, EFS, S3, Secrets Manager, DynamoDB, Step Functions, CloudWatch, and Synthetics Canaries.
</Note>

---

## 🤖 GitHub Actions CI/CD Secrets

Configure the following secrets in [`FilestoreCloud/infra`](https://github.com/FilestoreCloud/infra) → Settings → Secrets & Variables:

| Name | Type | Value / Purpose |
|---|---|---|
| `AWS_ROLE_INFRA` | Secret | IAM Role ARN assumed by GitHub Actions via OIDC federation. |
| `AWS_REGION` | Variable | Target AWS deployment region (e.g. `ap-southeast-1`). |
| `ENVIRONMENT` | Variable | Deployment environment tag (`dev`, `staging`, `prod`). |
