# Quickstart Guide

This guide walks you through deploying the complete Storix platform on AWS and provisioning your first isolated tenant.

---

## 🛠️ Step-by-Step Walkthrough

<Steps>
  <Step title="Clone the Repositories & Verify Local Tests">
    Clone the platform repositories and run the offline fast quality gate:
    ```bash
    git clone https://github.com/FilestoreCloud/infra.git
    git clone https://github.com/FilestoreCloud/runtime.git
    git clone https://github.com/FilestoreCloud/console.git

    # Run the comprehensive fast test suite
    make test-fast
    ```
  </Step>

  <Step title="Deploy Infrastructure via GitHub Actions">
    Trigger the end-to-end `deploy-all.yml` workflow via GitHub CLI or the GitHub Actions UI:
    ```bash
    gh workflow run deploy-all.yml \
      --repo FilestoreCloud/infra \
      -f environment=dev \
      -f skip_runtime_build=false \
      -f run_acceptance_tests=true
    ```
    This automatically builds the multi-arch Docker image, deploys CloudFormation Stacks 01 to 07, builds the SuperAdmin console SPA, and runs acceptance tests.
  </Step>

  <Step title="Access the SuperAdmin Console">
    Open the CloudFront domain for your SuperAdmin console (e.g. `https://admin.png261.dev` or run locally):
    ```bash
    cd console
    npm run dev
    # Opens local development console at http://localhost:5173
    ```
    Sign in using your configured administrative credentials, WebAuthn biometric passkey, or TOTP MFA.
  </Step>

  <Step title="Provision Your First Tenant">
    In the console, click **Create Tenant** or dispatch an authenticated API request:
    ```bash
    curl -X POST https://admin.png261.dev/api \
      -H "Authorization: Bearer <ADMIN_TOKEN>" \
      -H "Content-Type: application/json" \
      -d '{
        "action": "PROVISION",
        "tenant_id": "acme",
        "tenant_name": "Acme Corporation",
        "admin_email": "admin@acme.com",
        "domain": "acme.png261.dev",
        "quota_gb": 100
      }'
    ```
    The Step Functions SAGA orchestrates the creation of the PostgreSQL catalog, EFS access point, Fargate task, and ALB routing rules.
  </Step>

  <Step title="Verify Tenant Health & AI Assistant">
    Verify the tenant responds with `200 OK` and inspect assistant tools:
    ```bash
    curl -s -I https://acme.png261.dev/status.php
    # Expected: HTTP/2 200 OK
    ```
  </Step>
</Steps>

<Check>
  Congratulations! Your tenant is live, completely isolated in its own compute container, database catalog, and storage prefix, and connected to Amazon Bedrock generative AI.
</Check>
