# RAG Pipeline

## Overview

The RAG (Retrieval-Augmented Generation) pipeline enables Nextcloud's AI Assistant (`@assistant`) to answer questions grounded in tenant-specific documents stored in S3.

## Flow

```
User asks @assistant in Nextcloud
  → Nextcloud AI Hub
  → Vector search over tenant S3 files (Nextcloud Full-Text Search)
  → Retrieved context chunks
  → LiteLLM Bridge (127.0.0.1:4000)
  → Claude 3.5 Sonnet on Amazon Bedrock
  → Answer grounded in tenant documents
```

## Supported File Types

The AI assistant can analyze documents stored in Nextcloud:
- PDF, DOCX, XLSX, PPTX
- Markdown, plain text
- Code files (syntax-aware)
- Images (via Bedrock Vision)
